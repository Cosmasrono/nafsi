# Website fonts

Latin variable subsets of Syne (400–800) and Plus Jakarta Sans (200–800), recovered from the existing Next.js production font cache. They are bundled with `next/font/local` so the reference typography works without Google Fonts access during builds.

Both fonts use the SIL Open Font License 1.1; their upstream license files are included alongside them.

Sources:
- https://github.com/google/fonts/tree/main/ofl/syne
- https://github.com/google/fonts/tree/main/ofl/plusjakartasans
